# 0001. Architecture

Accepted. The primary consumer converts untrusted documents in a child process and OCRs in its parent; PDF must share the document model, and recovery must report dropped content.

## Decision

1. **Distribution.** Crate `almiladoc` and unpublished abi3 binding `python/` (PyPI `almiladoc`) share a version; `fuzz/` is separate. Both declare `BUSL-1.1 AND MIT` and ship ADR 0003's `LICENCE_SET`; default features are `pdf`/`raster`, optional `serde`/`ocr-http`, all enabled by the binding; rten stays outside this graph (ADR 0002 decision 8).
2. **API.** `Converter::new(Config)` validates configuration/limits; `inspect`, `parse`, `convert` and `convert_with_ocr` take checked `Input::new` or detected `Input::auto`, optional cancellation and PDF page selection, with one budget for detection, label validation and parsing (`Format::sniff` is separate). `Parsed` retains configuration/diagnostics for render, `Conversion::units()` gives Markdown byte spans, public extensible types are `#[non_exhaustive]`, and `Converter` is `Send + Sync`.
3. **Threads.** Input walks use `install` on a per-call pool of `Config::threads` (default 1), including PDF extraction; no global pool. Stack size is measured per-level cost times decision 12's ceiling.
4. **Inspect.** PDF only: container facts, diagnostics and 1-based pages with `Text`, `Blank` (`no_text`) or `NeedsOcr { reasons }`; other formats are `Unsupported`.
5. **Model.** Asset ids freeze in first-reference order: body, chosen notes, headers/footers, then unreferenced payloads in retention order; image/OCR origins share that mapping without changing payloads or gap ids. The model carries resolved super/subscript, typed unit milestones and document-scoped anchors with optional destination units; only that unit being unread suppresses a missing-anchor loss.
   - Empty readable units retain ordinals/zero-length spans; hidden omitted or unreadable units have no milestone, except surviving PPT slide-list text. `Block::Gap` carries opaque `{optional unit, ordinal}` ids; `Parsed::gaps()` visits every container in document order, including settled gaps, with origin/reasons.
   - Kept limits govern fills; `GapError` is `UnknownGap`, `Settled`, `InvalidLine`, `InvalidTable`, `Refused { limit }` or `Convert` (only work-limit, cancellation or internal errors). Refusal changes nothing, including fuel; ADR 0002 owns fills and failures.
6. **PDF.** Use crates.io unpdf 0.52.0, defaults off, sequential `for_each_page(PageStreamOptions)` starting no thread; map blocks/style and rule page verdicts from text/image operators, coverage, suppressed runs, fonts and undecodable streams. Count unread text only where clip/page box shows it.
   - unpdf bundles Adobe CMaps/Glyph List and PDFium CMYK data (BSD-3-Clause), Core14 widths (Adobe AFM notice) and Unicode Adobe vendor mappings (Unicode notice).
7. **Adapters.** Crate-private readers receive one `ParseCtx`; ZIP facts come only from the central directory, rejecting duplicate names (`Malformed`, ASCII-case-folded for OPC). Sniffing reads bounded metadata/relationships; a contradictory label is `Unsupported { kind: FormatMismatch { detected } }`.
   - DTD entities never expand: internal subsets fail OOXML/ODF but are ignored in EPUB ([XML constraints](https://www.w3.org/TR/epub-33/#sec-xml-constraints)); XHTML resolves HTML5 names and reports unknown ones as Lost. Mismatched/unclosed elements, malformed or duplicate qualified/expanded attributes, unbound prefixes, undecodable bytes and unknown declared encodings make required XML `Malformed`, optional XML unreadable according to role; multiple roots, top-level text and non-`Char` characters still parse.
8. **Serializer.** [Support](../support.md) owns output behavior, policy losses, images, tables, lists and links; unit spans exclude anchors, separators, boundary whitespace, final newline and appended notes. Nonempty slides have one thematic-break separator; empty slides retain milestones/anchors without separators.
   - Emphasis uses one outer-first stack: super/subscript, `~~`, `**`, `_`; retain shared prefixes, close in reverse, leave edge whitespace outside, close at line/hard breaks, keep marks outside code fences and table-heading bold beneath cell marks. When CommonMark 0.31.2 §6.2 flanking (`~~` as `*`) fails, encode only the neighboring source character numerically (`a&#98;_c_`); non-ASCII non-alphanumeric/non-whitespace and circled/squared Latin So letters must flank both as punctuation and as not.
   - Raw HTML is restricted to escaped super/subscript, anchors, cell `<br>` and page OCR comments, plus opt-in safe OCR tables (ADR 0002). First eligible note definition wins even when empty, before consuming bodies, numbering, anchors or losses; Omit prunes only image-emptied chosen notes and dependent references, never defined-empty references.
   - Nested links split at the nearest target, equal-target source pieces rejoin, blank pieces keep whitespace and URL fallback is judged over the whole link; blank internal labels stay whitespace, safe empty external labels use destinations and heading slugs use emitted labels. One WHATWG-preprocessed destination gate admits only HTTP(S), mailto, anchors and relative paths, escapes `\`/`&`, and otherwise retains the label with `unsafe_link`; unused image destinations under AltText/Omit are never inspected.
   - OLE previews occupy the object's place with only its source description; without a preview use a description marker or nothing, while payload assets remain unreferenced. A MathType or Equation Editor object whose MTEF decodes (`shared::math::mtef`) takes that place as TeX instead: display math alone in its paragraph or frame unless MathType marks it inline, inline beside text, in headings and in cells. RTF reads `\objdata` as an OLE1 object, DOC `ObjectPool/_<sprmCPicLocation>` in its own compound file and PPT `ExOleObjStg` through `shared::inflate`; an object that does not decode keeps its preview and `embedded_object`. Hidden/deleted pictures report only their policy omission.
9. **Errors.** `ConvertError` variants and input-free message rules live in [error.rs](../../src/error.rs); public snake_case codes never rename after release. Recovery propagates `ResourceLimit`, `Cancelled`, `Internal`; refused allocation is `ResourceLimit`, boundary panics `Internal`, and invalid call configuration reuses `ConfigError` through `InvalidConfig`.
10. **Diagnostics.** Bounded, aggregated `{code, class, region, unit, count}` without free text; no diagnostic is dropped. [Support](../support.md) owns classes/output, including `NeedsOcr` before `Incomplete` under default Fail; the crate has no logging facade.
11. **Content policy.** [Support](../support.md) owns comment, revision, hidden, header/footer and image semantics; every policy participates in identity. Header/footer values are rich blocks: empty clears, `None` inherits default (`uses default` in its label); compare only within the same named page style, suppress consecutive equals, preserve A→B→A and always repeat a value read with loss.
    - Each change opens a labelled blockquote with `<a id="almiladoc:REGION:VARIANT:N"></a>Header (VARIANT):` (or Footer), adding escaped ` of page style NAME` for named source styles. Readers publish at their section/master/sheet/slide/page boundary; side losses repeat in each showing unit/region, assets follow body/notes, and image OCR applies there too.
    - Side anchors are prefixed by their label id, disjoint from colon-free body ids; headings claim no slug, and body↔side links and ordinary side-note references remain dangling. Comments have a separate namespace, can be referenced by emitted side stories, and their assets follow headers/footers.
    - Printed dynamic fields become `{page}`, `{pages}`, `{date}`, `{time}`, `{file}`, `{path}`, `{sheet}` (`field_token`) without reading cached results; fixed/locked ODF (`text:fixed`), DOCX (`w:fldLock`), DOC (`grffldEnd.fLocked`) or RTF (`\fldlock`) fields keep stored content, PDF folios keep painted text. Discard spreadsheet print formatting as `formatting_unreadable`, judging damage on surviving text.
12. **Limits.** Defaults in [limits.rs](../../src/limits.rs) must admit ordinary large documents and document their reasons; ship a field only with its charge site and a default-limit abuse fixture. Every input-controlled recursion, rendering included, is capped below the compile-time nesting ceiling; one saturating ledger charges deterministic fuel and checks cancellation (OCR fill limits: ADR 0002 decision 11).
13. **PDF engine bounds.** Admit page count before extraction; unpdf receives limits/cancellation between pages and before every paint step, but decoding inside a page has only its fixed ratio rule and no caller budget. Consumers isolate PDF work in a memory-capped recyclable worker.
14. **No global state.** `clippy.toml` denies environment/filesystem/network/process/thread APIs (including canonicalization), rayon global/pool/parallel APIs, thread locals and once-cells, including PyO3 caches; architecture tests also ban non-test `std::{env,fs,net,process,thread}` imports because clippy cannot ban module paths. Exceptions are the call pool, scoped HTTP workers, binding file reads/exception module and tests: item-level reasoned `#[expect]` only, except one reasoned integration-test crate expectation and fuzz manifest allowances; no panic hook, recycle after `Internal`.
15. **Identity.** With committed lockfile, equal version/configuration/input/fills give byte-identical output across calls/threads and, except PDF, architectures; non-PDF code avoids [platform floating-point operations](https://doc.rust-lang.org/1.99.0/std/primitive.f64.html#method.powi). `config_fingerprint` excludes limits, threads and cancellation; patch releases never change Markdown that previously converted.
16. **Lints.** Every crate, fuzz included, forbids unsafe; manifests/`clippy.toml` own the warning/deny sets, gated with `-D warnings`, release overflow checks and unwinding. No inner allow/expect in core/binding; exceptions are named, reasoned items, and unsupported numeric conversions belong only in `shared::lossy` with rounding/saturation contracts.
    - Limits: 60 lines/function, six nesting levels, one bool parameter; split at named steps, except reasoned case/dispatch tables. Deny non-deterministic float methods and hash-order iteration/draining; exceptions explain why order cannot escape, and changes adding foreign hash types must extend the deny list because generic/owned `IntoIterator` escapes clippy.
    - Arithmetic side-effect lint stays off; indexing is locally guarded, except binary readers (`shared::binary`, `shared::officeart`, `shared::math::mtef`, `shared::ole_equation`, DOC sprms, XLS/XLSB) deny it at module declarations and use checked views/`ByteReader`, the sole little-endian decoder.
17. **Python.** Frozen Rust-defaulted configuration and per-call tokens mirror Rust, but the model crosses only as versioned JSON; each error code has a `ConvertError` subclass. Borrow `bytes`, release the GIL and admit other buffers before copying: [PyBackedBytes copies bytearray first](https://docs.rs/crate/pyo3/0.30.1/source/src/pybacked.rs#274-289).
18. **Gates.** Architecture tests enforce model→limits only, no adapter→renderer imports, context through `ParseCtx` and mutable statics only in decision 14's exceptions; default-limit abuse fixtures include deepest conversions on the call pool. Serializer/CSV/XML proptests, cross-target byte-identical non-PDF snapshots, same-target run/thread PDF snapshots, every-format fuzzing and injected OOXML/ODF part fuzzing protect these constraints; ADR 0003 owns daily campaigns.
19. **Release acceptance.** First candidate requires gap fills, engine port, rasterizer and HTTP OCR plus shim-free consumer integration; each later 0.x minor repeats consumer proof, and 1.0 additionally requires clean deny sets and completed campaigns. [Roadmap](../roadmap.md) owns remaining work, including measured stack costs before release.

## Rejected routes

- `Format::Image`: standalone images belong to the consumer's OCR; public caller-built-model rendering adds an unrequired API and uses the caller's stack; an ambient-read inventory adds machinery for three known reads.
- Release before OCR: forces the consumer to adopt and replace both PDF and `NeedsOcr` paths.
- Git unpdf dependency: [cargo publish rejects it](https://doc.rust-lang.org/cargo/reference/specifying-dependencies.html#specifying-dependencies-from-git-repositories); vendoring adds 50.6k lines of lint debt.
- Previous-engine fork: a 535-page, 22-document corpus falsely sent 12 text pages to OCR (eight garbled, four pixel-count scan verdicts), versus none from unpdf facts; weak paper extraction and no outside PR merged after 2026-08-06 leave 132k lines to maintain alone.
- Combining engines duplicates wheel parsers; pdfboss adds private threads, raw ligatures, no page facts and one-author maintenance; PDFium requires a native library. Historical licence-based rejections were MuPDF (AGPL-3.0) and Poppler (GPL).
