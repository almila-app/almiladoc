# Conversion limits

What each reader leaves out of the Markdown, and the `DiagnosticCode` that reports it. The diagnostics model, the loss classes and `OnLoss` are in the [README](../README.md#rust); the default of every limit is in the `Limits` rustdoc ([`src/limits.rs`](../src/limits.rs)).

## All formats

- **Pictures.** `ImagePolicy::Placeholder` writes retained assets as `![label](asset:N)` (`image_placeholder`, Deferred), unavailable sources as literal `[label]`, and external sources as gated text links. Labels retain source alt, or use `Image`. `AltText` writes the label; `Omit` writes nothing. Intentional image-content omission is `image_omitted` (Omitted). Actual image read failures are Lost only under Placeholder; source-free stand-ins are Deferred. An unplaced picture is Lost except under Omit. Assets remain in the model under every policy, bar a PDF's pictures, which are never read (see [PDF](#pdf)). Hidden and deleted pictures leave no marker.
- **Image OCR.** Under `ImageOcr::All` each embedded PNG or JPEG, judged by its bytes, leaves a gap after the block that shows it, which `Parsed::fill_gap` fills with the image's text, written after that block and, in a table cell, joined to it like the cell's other blocks; the image itself still follows its policy. A gap not filled writes nothing and reports `ocr_gap`, one whose OCR failed `ocr_failed` (both Deferred), and neither fails `NeedsOcr`. Every other image reports `image_not_ocred` (Omitted). A note that repeats an earlier note's id leaves none.
- **Tables.** A cell holds one line: a list or a table inside a cell is flattened into it, list items and nested rows joined by `<br>` and the cells of a nested row by ` / `. A one-cell table that holds a single table and, beside it, only paragraphs that show nothing is a frame: the table inside is written in its place, through frames up to the nesting limit. A merged cell is written once and its covered positions are blank, since GitHub-Flavored Markdown has no spans. A table without a header row gets an empty one.
- **Superscript and subscript.** `.doc`, `.docx`, `.pptx`, `.ppt`, `.rtf`, OpenDocument, EPUB and PDF write raised and lowered text as `<sup>` and `<sub>`; the other formats write it at the baseline, and no code reports that.
- **Escaping.** Text that Markdown would read as syntax is escaped: a paragraph that begins `1. ` is written `1\. `, so it does not become a list, and text right after a note reference that begins `(`, or `:` where the reference opens a line, is written `[^1]\(` or `[^1]\:`, so the reference stays one. Emphasis is written `**bold**`, `_italic_` and `~~struck~~`, closed at each line end; where a delimiter would not take effect beside the character next to it, that character is written as a numeric reference: `a&#98;_c_`.
- **Lists.** A decimal list whose numbers count up by one from its start and fit in nine digits, each bare or followed by `)`, is an ordered list (`)` only when every number carries it); an EPUB list holding a number below 1, and any other numbering, is written as bullets carrying the source label. A list right after a sibling list of its kind takes the other marker (`*` for `-`, `)` for `.`), so the two stay apart.
- **Links.** A link inside another splits it, each piece linking to its nearest target. A link whose target has a scheme other than `http`, `https` or `mailto`, or is a network path, keeps its label and loses the link: `unsafe_link`. A link to an anchor that exists nowhere keeps its label too, and `dangling_reference` also reports a note reference to a note that exists nowhere. The first eligible source note definition wins, including an empty one; `duplicate_note` reports each later definition. Losing definitions cannot contribute content, anchors or image losses.
- **Packages.** In the ZIP-based formats (`.docx`, `.pptx`, `.xlsx`, `.xlsb`, OpenDocument and EPUB), an XML part that a reference names and the package lacks, or that will not read, is `part_unreadable`; a part with a mismatched or unclosed element, an ill-formed or repeated attribute, an unbound prefix, bytes that do not decode or a declared encoding no decoder names does not read, and fails the conversion `Malformed` when the format needs it; an entity reference left literal is `unresolved_entity`. In a part that holds formatting alone, an unreadable part is `style_part_unreadable` and an EPUB stylesheet that does not decode is `invalid_style_encoding`, which cost no text, bar an EPUB stylesheet that may hide it (see EPUB); a `.docx` styles part that does not read is `part_unreadable` instead when the package has a numbering part, when its entry cannot be inflated, or when it does not parse and a `vanish` element outside comments, character data, processing instructions and the document type declaration does not turn off, since a style can hide text with it; a missing part or one rooted elsewhere stays `style_part_unreadable` in a package with no numbering part. `conventional_part_used` reports a part found by its conventional name because its reference does not resolve.
- **Units.** A diagnostic names the slide, sheet, EPUB chapter or PDF page it sat in, numbered from 1 by its place in the document's own list, so a hidden, unreadable or skipped entry keeps its number; past 64 units under one code and region, the highest fold into one count with no unit. A CSV is one sheet. Hidden sheets and unreadable units have no range, bar a PPT slide whose slide-list text outlives its lost container.
- **Alternate content.** `.docx` and `.pptx` take the first `mc:AlternateContent` choice whose required namespaces the reader supports, else the fallback. A chart, diagram or ink in a declined choice is reported as `graphic_unread`; a picture or text there is reported as `image_unplaced` or `block_unread` unless the fallback shows it.
- **Charts.** `.docx` and `.pptx` table a chart's cached series under the category labels of the first series that has any; a later series whose labels differ from those or run past them is reported as `graphic_unread`.

## Word

`.docx`, `.docm` and `.doc` are read for body text, headings, lists with their numbering, tables, footnotes and endnotes, and hyperlinks. `.docx` also reads text boxes, equations (as TeX), the text of charts and SmartArt, the picture a VML shape's `v:fill` of type `frame` or `tile` names and its own `on`, else its shape's `filled`, has not switched off (ranked after the other pictures of its drawing, or of the shape an object names as its preview; one not read is `image_unplaced`), and the preview picture an OLE object or ActiveX control names (a VML shape whose `id` is the `ShapeID` of `o:OLEObject`, the `w:shapeId` of `w:objectEmbed` or `w:objectLink`, or the `w:shapeid` of `w:control`; where it names none that holds a picture, the first picture no VML shape holds, such as the object's own drawing), shown in its place under the description of its drawing or its shape while an object's payload, where the package holds it, is kept as an asset. Tracked changes are accepted: inserted text stays and deleted text goes. Text in a Symbol, Wingdings, Webdings or Zapf Dingbats font, and an inserted symbol, reads as the character the font draws, a ballot box as a checkbox; `.doc` picks each character's font from its font table by the character and its script, and reads field instructions undecoded.

- **Lost, both:** `embedded_object` for an OLE object, whose content is not converted; `image_unavailable` for a picture whose bytes are not found or do not decode; `image_unplaced` for a picture that gets no place in the output, such as a floating one; `graphic_unread` for a shape or chart that is not read; `form_control_unread` for a check box or drop-down form field; `unmapped_symbol` for a symbol-font character with no Unicode mapping (`.doc` also: a private-use symbol code, U+F000-F0FF, in a text font or one the font table does not resolve). A loss inside a field instruction, which never renders, is not reported, except for the text boxes, charts, diagrams and display equations that render from it.
- **Lost, `.docx`:** `form_control_unread` for an ActiveX control (`w:control`) and `graphic_unread` for a movie (`w:movie`), neither read; `block_unread` for table rows or cells held in a content control, custom XML or alternate content, and for math in a declined alternate-content choice; `imported_part_unread` for an imported document (`altChunk`, `subDoc`); `ruby_unread` for ruby text; `field_value_unread` for a page number or date the file does not store; `link_target_unread` for a hyperlink whose relationship is missing and whose label is not a URL; `part_unreadable` for a styles part that does not read where it may hide or number text (see Packages).
- **Lost, `.doc`:** `text_box_unread` for body text boxes, which are never read; `truncated_records` for body or note text the piece table places inside the stream's declared length (`cbMac`) but past its end; `invalid_encoding` for shown text, or the target of a kept link, that does not decode; `part_unreadable` for a note, run- or paragraph-formatting or list table that does not read, a style table that does not read where it may hide or number text (see Info), and a note reference, neither deleted, hidden nor in a field instruction, that falls inside a surrogate pair.
- **Omitted:** `header_omitted` and `footer_omitted` for headers and footers, `comment_omitted` for comments, `revision_omitted` for deleted text and `hidden_omitted` for hidden text.
- **Info:** `numbering_unresolved` for a list that names a missing numbering definition and is shown unnumbered, and `table_span_repaired` for a merge that runs past its table (`.docx`); `formatting_unreadable` for run formatting that does not decode (`.doc` also: a character-style reference naming no character style, a style that holds a property a style may not, which is ignored, and shown text, kept as stored, in a font the font table does not resolve, once per font), `style_part_unreadable` for a style table that does not read (`.docx`: in a package with no numbering part, one missing, rooted elsewhere, or that does not parse and sets no `vanish`; `.doc`: in a document with no list tables, a record that does not parse, shows a style type holding no run formatting, none of paragraph, character and table, is no parsed style's base and inherits from none), `invalid_style_encoding` for a style name that does not decode, and `style_cycle` for a style that inherits from itself (`.doc`; a `.docx` one fails `Malformed`).

## PowerPoint

`.pptx`, `.pptm`, `.ppsx`, `.ppsm`, `.ppt`, `.pps` and `.pot` are read slide by slide, each slide a unit. A title is a level-2 heading, nonempty slide bodies are separated by `---`, and speaker notes follow their slide as a quote. Ownerless PPT notes precede the first slide, outside unit ranges. `.pptx` resolves the master, layout and slide text cascade and also reads tables, equations, the text of charts and SmartArt, and an OLE object's preview picture (`p:oleObj/p:pic`), shown in the object's place under the frame's description while the payload is kept as an asset.

- **Lost, both:** `unit_unreadable` for a slide that is listed and cannot be read; `embedded_object` for an OLE object; `form_control_unread` for a control; `image_unavailable` for a picture whose bytes are not found or do not decode; `link_target_unread` for a hyperlink whose label does not show its target; `graphic_unread` for media or any graphic that is not read; `unmapped_symbol` for a symbol-font character with no Unicode mapping.
- **Lost, `.pptx`:** `image_unplaced` for a picture-filled shape, a slide's own background picture and a picture in a declined alternate-content choice; `block_unread` for text in such a choice; `graphic_unread` also covers a chart there and text nested in a notes shape.
- **Lost, `.ppt`:** `image_unplaced` for every picture a slide shows, since none is written; `recovered_stream_order` when the persist directory is unusable and text is taken in raw stream order, which can include superseded edits; `invalid_encoding` for text that does not decode; `image_unavailable` also covers a picture store that does not read.
- **Omitted:** `hidden_omitted` for hidden DrawingML objects (`.pptx`); `header_omitted` for master and layout content a slide shows, a layout or master background picture included, and for header placeholders (`.pptx`; in `.ppt` a notes page's header text or a drawn header placeholder that holds text); `footer_omitted` for footer, date and slide-number placeholders (`.pptx`; in `.ppt` each of the three that a page's header and footer settings show or a drawn placeholder holds text for, once per page); `comment_omitted` for comments, once per page.
- **Info:** `formatting_unreadable` for text formatting that does not decode (`.ppt`).

## Excel

`.xlsx`, `.xlsm`, `.xlsb` and `.xls` are read alike: each visible sheet is a table, headed by its name when the workbook has more than one, and a formula cell shows its cached result. A cell is written with its number format when the format engine applies it; dates and times are always written as ISO-style text, whatever the cell's date format, and no code reports that. Check boxes anchored in a cell are written in it. A hyperlink keeps its label and drops its target.

- **Lost:** `unit_unreadable` for a sheet that is listed and cannot be read; `cell_value_unreadable` for a value that does not decode, a formula result the file never cached, or a cell outside the sheet's bounds; `number_format_unread` for a date, time, currency or literal-bearing format that falls back to General, and for a format the file declares and this reader cannot read, since it may hide the value (`.xls`: a FORMAT record that does not read and an XF record cut short; `.xlsx`: a `numFmt` with no code or no id, an id being the digits after leading white space and an optional plus sign, so `abc`, `-1` and a number past 32 bits are none; a record whose id does not read may have declared any id with no code, built-in or its own (in `.xls` only 5-8, 23-26, 41-44, 63-66 and 164-392) and costs what its code would hide under General, `number_format_unread` when it has none; a code that reads wins whatever the record order); `link_target_unread` for a hyperlink whose label does not show its target; `form_control_unread` for a control other than a check box; `image_unplaced` for a picture on a sheet; `graphic_unread` for a chart or a shape with text; `part_unreadable` for a styles or drawing part that does not read (`.xlsx`, `.xlsb`); `truncated_records` for a record stream that ends early (`.xls`); `invalid_encoding` for text that does not decode; `encoding_assumed` for text in a code page the file does not declare (`.xls`).
- **Omitted:** `hidden_omitted` for hidden sheets, rows, columns and controls; `comment_omitted` for comments; `header_omitted` and `footer_omitted` for print headers and footers.
- **Info:** `number_format_fallback` for a format that falls back to General where the same number shows, for the ids a `numFmt` whose id does not read may have declared when its code shows only its number (`.xlsx`), and `table_span_repaired` for a merge that runs past the sheet or does not read.

## OpenDocument

`.odt`, `.ods` and `.odp` are read for text, headings, lists, tables, footnotes, equations (as TeX) and the stored text of an index. A cell shows the content it holds, a `text:p` or `text:h` even when empty, else its typed value, written without the number style the cell names: its own, else its row's, else those of the columns its shown copies sit in, by `table:default-cell-style-name`, through parent styles; a name that resolves to no number style costs nothing. A spreadsheet leaves out its hidden sheets, rows and columns, those of a hidden group included, as the Excel readers do, and a merge they cut keeps the part that shows unless its origin repeats; a table in a text document, a presentation or a cell keeps its collapsed rows. A slide's title is a level-2 heading, and speaker notes follow the slide as a quote.

- **Lost:** `block_unread` for a numbered paragraph and for a non-paragraph block in a title frame; `text_box_unread` for a frame's text box that no paragraph holds; `image_unplaced` for a picture outside paragraph text; `image_unavailable` for a picture whose bytes are not found; `embedded_object` for an OLE object, a floating frame, an applet, an object that is not a formula or chart, and a formula in a frame no output places; `graphic_unread` for a chart, a 3D scene, media and the text of a drawing shape that is not on a slide; `number_format_unread` for a value that is not a string, shown without a number style other than a float's `number:number-style` of one plain `number:number` and a percentage's `number:percentage-style` of one and a `%` after it; for a string, shown without a `number:text-style` that is not `number:text-content` alone, since the style may show the value otherwise or hide it; and, in a spreadsheet whose `styles.xml` is `style_part_unreadable`, for a value shown without a number style when its cell, row or column style, a parent style or its data style is held by no part, since the unread part may have declared it; `form_control_unread` for a control, bar a check box that a table cell anchors and its table declares in a state other than mixed, which is written in the cell; `unmapped_symbol` for a formula glyph with no TeX form; `part_unreadable` for a text or presentation `styles.xml` that is present and does not read, and a spreadsheet's where it may hide a sheet or text (see Info).
- **Omitted:** `header_omitted` and `footer_omitted` for the running headers and footers of the master pages a text document uses, for the header, footer, date and page-number frames of a slide or its notes, and for the header, footer and date-time declarations a slide uses and shows; `header_omitted` also, once per master page, for a presentation master's own shapes that are not placeholders and its bitmap background, where a slide using it leaves them visible; `comment_omitted` for annotations; `revision_omitted` for tracked deletions; `hidden_omitted` for text and sections hidden by `display`, and for a spreadsheet's hidden sheets, rows and columns.
- **Info:** `number_format_fallback` for a float shown without a `number:number-style` of one plain `number:number`, or a percentage without a `number:percentage-style` of one and a `%` after it, which shows the same number; `table_span_repaired` for a covered cell that no span accounts for, and `style_part_unreadable` for a spreadsheet's `styles.xml` that does not read (a value shown without a style it may have held is `number_format_unread`), which is `part_unreadable` instead when its entry cannot be inflated, or when it does not parse and a `table-properties` element sets `table:display` to `false` or a `text-properties` element `text:display` to `none`, outside comments, character data, processing instructions and the document type declaration (a `display` holding an entity, or an attribute list that stops reading, counts), since a style can hide a sheet or text with it. A style that inherits from itself fails `Malformed`.

## Rich Text Format

`.rtf` is read for text, lists, tables, footnotes, hyperlinks and equations. Pictures are kept as assets and rendered by the image policy. Text in a Symbol, Wingdings, Webdings or Zapf Dingbats font reads as the characters the font draws, a ballot box as a checkbox, and a private-use symbol code (U+F020-F0FF) in a text font reads through the last symbol font used. Field instructions, bookmark names, list labels, equations and picture properties are read undecoded, so a symbol-font `\listtext` label shown for want of a list table reads undecoded, in the code page.

- **Lost:** `unclosed_structure` for groups still open at the end of the input; `encoding_assumed` for text whose code page the file does not declare or this reader has no table for; `invalid_encoding` for text that does not decode; `field_value_unread` for a page number, date or time control word; `form_control_unread` for a drop-down or check box field; `embedded_object` for an object; `image_unavailable` for a picture in a format that is not read; `unmapped_symbol` for a symbol-font code no glyph table maps, or a private-use symbol code with no symbol font used before it.
- **Omitted:** `header_omitted` and `footer_omitted` for headers and footers, `comment_omitted` for annotations, `revision_omitted` for deleted text and `hidden_omitted` for hidden text.
- **Info:** `unmatched_close` for a group close with no open group, `style_cycle` for a style that inherits from itself, the acyclic prefix being kept, `invalid_style_encoding` for a style name that does not decode, and `formatting_unreadable`, once per font, for shown text in an `\fN` that a non-empty font table does not define.

## EPUB

`.epub` is read chapter by chapter in spine order, each chapter a unit, for headings, paragraphs, lists, tables, images, links inside the book and MathML equations. Of CSS only bold, italic, line-through, `vertical-align` on inline elements and `display: none` are applied, from inline styles and from a `link` or `style` whose `media` list holds on a screen. Of the rules inside at-rules, those in `@media` apply when its query names `all`, `screen` or no type and has no feature (`print`, `speech`, every other type and a query whose type is followed by anything but `and` and a feature never apply, and `not` inverts a well-formed query); those in `@media` with a feature, `@supports`, `@layer`, `@container` or `@scope` are unsettled and contribute only a `display` that shows; other at-rule blocks style nothing. A rule nested in a rule is skipped, `@charset`, `@namespace` and `@import` end at their `;`, another `;` outside a block joins the rule after it, which is then skipped, and an `@import` is not followed. A linked stylesheet is decoded as UTF-16 behind a UTF-16 byte order mark, else as UTF-8.

- **Lost:** `unit_unreadable` for a spine item that names no chapter or a chapter that cannot be read; `part_unreadable`, once in each chapter that links the sheet under a `media` list a screen may hold, for a linked stylesheet whose entry cannot be inflated and for one that does not decode when, outside comments, a replacement character sits in a declaration name, or in a rule or the group condition above it that declares `display`, among the rules a screen reads, since a sheet can hide text with it; `image_unavailable` for an image whose part is missing; `graphic_unread` for audio and video; `embedded_object` for `object`, `embed` and `iframe`, whose fallback content is still read; `block_unread` for text a list or table holds outside the items and rows the reader walks; `unmapped_symbol` for an equation glyph with no TeX form.
- **Omitted:** `hidden_omitted` for content under `display: none`.
- **Info:** `style_part_unreadable` for a linked stylesheet that is missing, and `invalid_style_encoding` for one that does not decode and is not lost.

## CSV

`.csv` is read as one table. The encoding is taken from the byte order mark, else UTF-8, else windows-1252, and the delimiter (comma, semicolon, tab or pipe) from the data.

- **Lost:** `encoding_assumed` for a file that is not UTF-8 and is read as windows-1252, and `invalid_encoding` for a UTF-16 file with bytes that do not decode.

## PDF

`.pdf` is read page by page with unpdf, each page a unit, for headings, paragraphs, lists, tables with their spans and code blocks of lines set in a fixed-pitch font; bold, italic, struck, raised and lowered runs keep their marks. A link annotation is not read: its text stays and its target is lost, unreported. A paragraph that is no heading, holds at most 80 characters besides spaces and whose words, digits aside, recur on at least half the pages that hold text, beside other text on two of them, with numbers that stay the same, or for a bare number that keep step with the page number, is a running head or folio when a page it recurs on also holds text that is none, and is dropped where it leads or trails a page's text. unpdf itself leaves out a bare page number in a page's top or bottom margin, and that is not reported. In a run the clip and page box show, a composite font's code that neither its `ToUnicode` map nor its own data reads, in a run whose other codes they read, is left out and reported. Each page's verdict is ruled from the facts unpdf reports of it, and `Converter::inspect` reports it as a `PageVerdict`: `NeedsOcr` with each `GapReason` that holds, else `Blank` for a page that shows no text, else `Text`.

- `UnreadableContent`: a content stream does not decode, or the page does not parse.
- `InvisibleText`: the page's OCR layer was dropped as unreadable, nine tenths or more of the characters it shows are invisible, or it reads no text and some of its text is clipped away.
- `GarbledText`: it reads no text and some runs were suppressed for their font.
- `ImageBacked`: it paints an image and reads no text, or an image covers nine tenths of it and each of its texts recurs, digits aside, on another page, or all of them lie in its margins.
- `VectorDrawn`: it reads no text, paints no image and fills paths.
- `UnreadableText`: none of these, yet it shows text that reads nothing, unless that text is only whitespace.
- `CallerRequested`: `Input::with_ocr_pages` selects it, after any reason above; its text is discarded and reports no loss, and running heads and folios are still judged across every page.

A page that needs OCR becomes a gap: under `OnLoss::Fail` the document fails `NeedsOcr` with every such page not filled, before any `Incomplete`, and under `Report` the gap writes `<!-- needs-ocr page N -->`. `Parsed::fill_gap` renders the caller's OCR in the gap's place, Markdown whose tables, strikethrough, emphasis, headings, lists, quotes and code are kept, raw HTML kept as text, a link as its label and an image as its alt; `Parsed::fail_gap` makes the gap write `<!-- ocr-failed page N -->`. With the default `raster` feature an OCR request carries the page painted as an RGB PNG of its crop box turned by its `/Rotate`, at the largest dpi up to the engine's `RasterSpec` at which its media box's pixels fit its cap, the pages of one call or engine batch painted on the pool at once; a page that cannot be painted asks for none and its gap stays.

- **Deferred:** `ocr_gap` for each page that awaits OCR, and `ocr_failed` for each page whose OCR failed.
- **Lost:** `unit_unreadable`, counting the pages a PDF declares that its page tree does not hold. `raster_incomplete`, once a page's gap is filled, for each text run, image, inline image and content stream its latest request's image left out; a shading or soft mask painting skips counts none. `garbled_font_encoding` for each text run suppressed for its font's encoding, a composite font's codes that nothing maps or a simple font's that decode to binary noise, on a page that reads, and for each code left out of a run whose other codes read; a font's codes that deliberately give none, such as an emoji cluster's extra glyphs, are not reported.
- **Omitted:** `image_omitted` for each image a page that reads paints, and `header_omitted` and `footer_omitted` for each running head or folio dropped from a page's start or end.
